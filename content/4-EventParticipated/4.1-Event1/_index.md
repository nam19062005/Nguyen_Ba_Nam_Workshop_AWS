# Event Recap: Swinburne Cloud Mastery

---

### 📌 Event Information

| Information | Details |
| :--- | :--- |
| **Event Name** | Swinburne Cloud Mastery |
| **Time** | 9:00 AM, July 4th, 2026 |
| **Location** | Floor 26, Bitexco Tower, 02 Hai Trieu Street, Saigon Ward, Ho Chi Minh City |
| **Role** | Attendee |

---

### 🎯 Event Purpose

The **Swinburne Cloud Mastery** event was organized to:

- Share practical knowledge, skills, and real-world experience in **Cloud Computing** from industry experts.
- Connect the community of students, engineers, and technology professionals interested in Cloud in Ho Chi Minh City.
- Introduce modern Cloud trends and solutions currently applied in enterprise environments.

---

### 📝 Event Content

#### Practical Cloud Computing Knowledge Sharing
- Expert speakers with years of Cloud experience shared a comprehensive overview of the Cloud adoption journey in enterprises.
- Presented **real-world case studies**: how organizations transitioned from On-premise infrastructure to Cloud, optimizing costs and improving system reliability.

#### Featured Cloud Services
- In-depth introduction to core services like **Compute (EC2, Lambda)**, **Storage (S3)**, **Database (RDS, DynamoDB)** and the AWS ecosystem.
- Discussion on strategies for selecting appropriate Cloud services for specific business problems.

#### Hands-on & Learning Experience
- Speakers shared self-learning roadmaps, approaches to AWS certifications, and experiences building personal Cloud portfolios.
- Guided hands-on practice with basic Cloud labs to help beginners confidently approach the technology.

---

### 💡 Key Takeaways

#### Technical Knowledge
- **Solid Cloud Foundation**: Gained a clearer understanding of IaaS, PaaS, SaaS models and how to choose the right fit for each use case.
- **Cloud-native Mindset**: Learned to approach system design with scalability, resilience, and cost optimization from the ground up.
- **Hands-on Confidence**: Gained confidence to start practicing with AWS Console and CLI after hearing from industry experts.

#### Soft Skills & Networking
- Expanded network within the **Vietnamese Cloud community**, meeting engineers and students pursuing the same Cloud journey.
- Learned effective **technical storytelling** — how experts explain complex concepts in an accessible way.
- Recognized the importance of **continuous learning and staying updated** in the rapidly evolving cloud technology landscape.

#### Personal Direction
- Clarified personal development roadmap: **prioritize completing the AWS Cloud Practitioner certification** first, then advance to specialized certifications.
- Gained additional motivation to complete the Workshop project in the FCAJ Bootcamp program.
