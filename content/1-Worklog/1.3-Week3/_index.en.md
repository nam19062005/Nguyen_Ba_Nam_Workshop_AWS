### Week 3 Objectives:

* Get familiar with database models (RDS/DynamoDB), Serverless architecture (Lambda, API Gateway), and containerizing applications with Docker/ECR.

### Week 3 Achievements:

* Successfully deployed an RDS database and connected to it from the application server.
* Built a complete Serverless REST API combining API Gateway and Python Lambda.
* Proficiently packaged application using Docker and stored it on Amazon ECR.
